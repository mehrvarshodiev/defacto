# DeFacto Dushanbe

Modern React + TypeScript + Tailwind CSS e-commerce storefront for DeFacto Dushanbe.

- React + Vite + TypeScript
- Tailwind CSS
- React Router
- Redux Toolkit + RTK Query
- Tajik / Russian / English UI
- Dushanbe delivery and Rudaki 77 pickup
- Cash on Delivery, Korti Milli, Alif Mobi
- WhatsApp / Telegram ordering
