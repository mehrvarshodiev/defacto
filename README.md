# DeFacto Dushanbe

Premium mobile-first clothing e-commerce storefront for DeFacto Dushanbe.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- React Router
- Redux Toolkit (cart, filters, checkout, products, wishlist, orders, user)
- Lucide React

## Store UX
- Women / Men / Kids catalog
- Product detail with size and color selection
- Persistent cart-ready Redux architecture
- Express delivery in Dushanbe
- Store pickup: 77 Rudaki Avenue
- Payment options: Cash on Delivery, Korti Milli, Alif Mobi
- WhatsApp / Telegram order shortcuts
- TJ / RU / EN language selector
- Responsive premium retail UI
